# Software Environments Help

1. Each application has one page under the `apps/` directory of the docs
tree. 
2. If an application has a page, check the Available-section to see if it's available on Roihu. 
3. Use the page to tell the user how to load and use it. 
4. If the application isn't already available, use `/opt/docs/computing/installing.md` to guide the user in the installation.
